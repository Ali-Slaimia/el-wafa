# WAFA BATIMENT — Site vitrine

Site one-page pour **Société El Wafa de Bâtiment** (Bizerte, Tunisie).

**Live:** [https://el-wafa.netlify.app](https://el-wafa.netlify.app)

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- Formulaire de contact → `alislimia01@gmail.com` via FormSubmit

## Développement

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Production / Netlify

```bash
npm run build
```

Déploiement : **Netlify** (voir `netlify.toml`).  
Build command: `npm run build` — Next.js plugin activé.

## Contact

Les messages du formulaire partent vers `alislimia01@gmail.com`.
Au premier envoi, FormSubmit peut demander une confirmation de l’adresse email.
